## 当前源码能力

| 能力 | 代码范围与验证边界 |
|---|---|
| 主控箱接入 | 唯一业务进程持有 MAVLink 串口，被动接收 F407 身份，支持串口发现、断线与节点编号复核。 |
| 遥测与运行状态 | 发布完整快照、实时遥测、注册与运行三态；设备类型固定为 `cns_box`。 |
| 控制与教学实验 | 保留主控箱控制回执、运行参数配置、只读自检、H1/M1 与链路排障入口；跨端验收单独留证。 |
| 首次部署 | 通用预装镜像、自动获得 F407 编号和首次服务器确认已有代码；镜像真实启动须另验。 |
| 远程更新 | Web MQTT 更新请求、HTTPS 任务领取、预编译包安装与回退已有代码；服务器/Web、ARM64 包及纯 5G 验收须分别记录。 |
| 运行维护 | 保留 5G 监测恢复、有界日志、systemd 自启与 watchdog。 |

## 后续验收

1. 核实当前源码在实体 Pi 的 ARM64 构建、首次启动、MQTT 注册、7 类发布 Topic 和串口恢复。
2. 在服务器/Web 完成设备确认、更新任务、版本选择、安装回报和回退联调，并记录纯 5G 条件下结果。
3. 分别核对 F407 固件、实验真实 TX/RX、Server 路由、落库和 Web 展示；本地合成测试不得代替硬件或跨端验收。
4. 完成现场配置保留、断电恢复和持续运行验证；容量指标以独立压测结果为准。

当前业务发布 Topic 为 `registration`、`telemetry/snapshot/v1`、`telemetry/realtime/v1`、`runtime/status/v1`、`config/ack`、`control/ack` 和 `experiment/ack`。配置、控制与实验的 `set` Topic 是订阅入口。维护更新的独立接口见[远程更新接口契约](远程更新接口契约.md)。

历史发布说明和 `change_history` 只记录对应日期的事实，不构成当前功能指引。本次清理未部署实体 Pi 或生产服务。
