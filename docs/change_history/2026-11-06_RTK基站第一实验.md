# 2026-11-06 RTK 基站第一实验

分支：`codex/rtk-base-station`。场景已纠正为 CNS 箱内 Pi 的三链路组合：F407、3DR/PX4 与 9Ps 各用独立串口。RTK 在原主流程启用，唯一 MQTT 身份属于 F407 箱子；随后用户授权使用已有缓存箱子绑定验证未连接 F407 时的 RTK。没有修改服务器或 F407 固件，不恢复旧 PX4/QGC 自动模式。

## 变更范围

- 新增默认关闭的 `rtk_base` 配置。`device/baud` 属于基站，新增 `px4_device/px4_baud` 属于 3DR/PX4；两者使用不同的明确绝对路径。`serial.device/baud` 仍属于 F407，可为 `auto`，发现排除 RTK 两个设备及其别名。
- 独立 PX4 会话以 PX4 autopilot 心跳与同 system 的真实 Basic ID 核验实验身份。失联清空该实时状态，冲突不改绑；PX4 ID 仅作实验元数据，不写入 F407 持久绑定或共享状态，不从 UID/Pi 序列号补身份。
- 基站串口混合解析 UBX、NMEA 和 RTCM，分别校验并记录原始状态、样本年龄和计数；过期或未知值不伪报成功。
- 增加 `rtk_base_status`、`rtk_base_survey_in`。Survey-in 只写接收机 RAM，经 ACK 与完整参数读回确认；动作配置完成与后续 NAV-SVIN 测量完成分开。
- 使用唯一 F407 箱子 `device_id` 和 `cns_box` 类型注册。遥测外层、Topic 和实验 target 都属于箱子，新增 `telemetry.rtk={base,px4,box_identity_verified}`。
- 沿用箱子 `experiment/set` 与 QoS 2 ACK outbox；完成回调确认后删除原 ACK。已有合法持久绑定且无冲突时，允许缓存箱子身份上报 RTK；F407 未实时业务在线时不携带旧普通传感数据，runtime 如实 cached/offline/unknown。无绑定时只保留本地 base/PX4，不独立注册 PX4。
- 保持 F407、G2、5G、配置/控制和维护服务流程；PX4 失联不关闭箱子 MQTT。本地状态新增 `box:{device_id,identity_verified}`。不向 PX4 转发箱子控制、不转发 RTCM、不接入 NTRIP。

设计范围与身份策略同步至 V1 设计文档、设备标识符、遥测协议和 CLAUDE；操作、请求及结果字段见 [RTK 第一实验接口](../RTK基站第一实验操作与接口.md)。

## 当前实现与缓存身份验证

当前结果见 [缓存箱子身份的 Pi 与云端验证](../validation/2026-11-06-rtk-box-cached.md)。最新 WSL 全量 68/68 CTest（19.82 秒），Pi ARM64 相关测试 8/8，增量构建 0 条警告；新版 `cns_rpi` SHA-256 为 `f66e617a7bbff24f54ec072a70c1746bb5bdc58c45f3854357c3455cfafe69c4`。

本轮修复合法新鲜度下限的配置失败：`stale_after_ms=1000` 时，固定 1Hz 的 MON-VER 查询与新鲜度门限竞争；缓存箱子身份、F407 未连接且主循环约每 `100ms` 运行一次可复现。查询间隔现为 `min(1000ms, stale_after_ms / 2)`，默认 `3000ms` 仍为 1Hz，下限 `1000ms` 为 2Hz，保持原新鲜度判定。

专项回归先用真实主程序的 PTY 测试复现失败，再验证修复通过；驱动共 24 个用例、482 项断言通过，三条 PTY、`1000ms` 门限的真实主程序四阶段流程也通过。这些专项结果与后续实体 Pi、MQTT、HTTP 证据分别记录，不能用于宣称室外定位验收。

随后真实 HTTP 核对发现，缓存身份的 43 帧 MQTT 遥测和操作 ACK 成功，但快照尚未落库：现有服务器 `ParseTelemetry` 要求 schema 3 根级 `drone_id` 与 `basic_id` 均为对象。Pi 缓存 RTK 快照现补精确空容器 `"drone_id":{"basic_id":{}}`，不填 `id_type`、`ua_type` 或任何 F407 实时观测值；schema 1 实时帧仍无 `drone_id`，服务器代码未改。服务器源码 probe 已证实缺容器时拒绝、补空对象后 accepted 且 payload unchanged；三 PTY 新结构断言用旧二进制先 RED，修复后的全量与 Pi 测试通过。补容器前的 MQTT 成功不作为落库证明，后续以正式 HTTP 新快照确认。

最终实测使用 Pi `192.168.0.244`，F407 未接，以合法缓存箱子 `DCDWCNS1GHC0G6LF8MY6` 唯一注册 `cns_box`。`2026-11-06T06:26:32Z–06:26:35Z` 收到 37 帧 RTK 遥测/44 条消息，runtime 身份为 `cached`、`box_identity_verified=false`，无旧 F407 值；基站查询 `completed`，Survey-in RAM 配置 `accepted → completed`、读回 `verified`（60 秒/2 米）。真实 PX4 子 ID 为 `393233510c004b0031`，未出现新 PX4 独立注册，1 条历史 retained 消息不计；随后 8 条 1Hz 状态正常。

正式 `GET /api/devices/DCDWCNS1GHC0G6LF8MY6` 返回 200，`telemetry_received_at=2026-11-06T06:26:39.921Z`；最新快照含配置 `verified` 与 PX4 子 ID，观测对象仅 `rtk/cellular_5g`，证实 schema 3 空 `basic_id` 兼容有效。原服务已恢复 active，正式程序、配置、绑定前后 SHA-256 一致，未替换正式程序、未提交或推送。F407 接回后的实体三链路/G2 同时运行、室外 Survey-in 成功、移动站 Fixed、网页实验页面仍未验或未做，不能称为整体验收通过。
