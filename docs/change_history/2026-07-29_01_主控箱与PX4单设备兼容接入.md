# 变更记录：主控箱与 PX4 单设备兼容接入

日期：2026-07-29

## 变更摘要

一台树莓派一次只连接一台受控设备。树莓派程序新增同一套运行时兼容 CNS 主控箱和真实
PX4 飞控的能力，并把受控设备主身份、Remote ID 与树莓派网关身份拆开。

## 已实施

- 新增 `device.mode=auto|cns_box|px4`；未配置时默认 `auto`。
- 自动模式按严格 HEARTBEAT 特征识别主控箱或 PX4，并锁定 MAVLink sysid/compid。
- 主控箱继续从 20 字符 Basic ID 得到 `device_id`。
- PX4 主动请求 `AUTOPILOT_VERSION`，优先用 `uid2`、回退 `uid` 生成 `device_id`。
- Basic ID 原始帧继续作为 Remote ID 保存，但不再无条件写入主设备身份。
- 同一 MAVLink system 的其他 component 可以提供遥测和 Remote ID；控制类消息固定到
  已识别的主 component。
- 注册与遥测升级为 MQTT schema v2，包含 `device_id`、`device_type`、端点和网关信息。
- 串口断线时发布 offline、关闭 MQTT、清空设备状态并重新发现；树莓派 CPU Serial
  仅作为 `gateway_id` 保留。
- 现有主控箱私有控制命令不会发送给 PX4，而是返回
  `unsupported_device_type`。

## 验证

- WSL / GCC 12.3，C++23，`-Wall -Wextra` 完整编译通过，无警告。
- `ctest --output-on-failure`：31/31 测试通过。
- 新增测试覆盖设备类型识别、PX4 UID 优先级与回退、身份请求消息、Basic ID 身份隔离、
  schema v2 注册/遥测，以及断线状态清理。

## 后续

本次只修改树莓派代码。`cns_server` 仍需增加 MQTT topic 的 PX4 `device_id` 校验、
schema v2 注册与遥测解析、数据库通用设备模型以及 Web 分类型展示，完成前不能认为
端到端链路已经上线。
