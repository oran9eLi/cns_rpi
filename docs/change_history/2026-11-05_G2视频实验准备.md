# 2026-11-05 G2 视频实验准备

分支：`codex/g2-video-preparation`。先完成本地 Pi 代码准备，WSL 构建、CTest 57/57 和独立复审通过；随后按用户指令部署至实体 Pi，启用现场视频配置并退出该 Pi 残留的旧只读配置卷。不改服务器或 F407。

## 变更范围

- 新增默认禁用的 `video` 配置，旧配置缺少该对象仍可加载，不自动采集。
- 新增摄像进程管理，以及 `video_probe/video_test/video_start/video_stop/video_status` 五项操作，沿用 schema 1、既有 `experiment/set`、`experiment/ack` 和 QoS 2 outbox。
- Pi 与 F407 保持同一业务 `device_id`，不新增摄像资产身份，不访问 UART。摄像任务受 Session/租约控制，不以 F407 业务在线作为视频门禁。
- probe/test/stop 异步完成后才回最终 ACK。start 完成只表示子进程已启动；实时编码、接收及播放未知事实不伪报成功。
- 有限 test 录制 TS 后由 ffprobe 验证 H.264、正编码帧数和匹配尺寸；采集进度与编码事实分开。
- 同动作重投去重为进程内最多 128 项、300 秒，不持久化到重启之后。
- 进程内最高租约跨 Session 单调；关闭视频子进程的非标准描述符，避免继承 UART 锁。历史查询显式标注运行及 Session 归属。
- 现有配置更新在活动视频、待交付终态或实验 ACK outbox 非空时返回忙，避免主动重启丢失视频动作结果；队列满只跳过该请求，继续维护主循环。

配置、参数精确范围、请求示例及运行边界见 [G2 树莓派视频实验接口与本地验证](../G2树莓派视频实验接口与本地验证.md)。
