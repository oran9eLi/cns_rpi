# 阶段一 H1 真实回显树莓派端

日期：2026-09-23

## 变更摘要

按候选跨端契约在原 MQTT/串口主进程增加受限学生文本 `uart_echo`：严格解析请求、复用唯一 MAVLink 串口读写者、保存完整帧和已应用速率、匹配 F407 原样回显及本动作后新业务帧、发布 QoS 2 终态 ACK。新增发帧前持久化去重记录，防止进程崩溃后同一动作盲目再次发送；ACK 只有获得 MQTT 完成回调才移出待发队列。旧 `inspect_pi_link` 仍为独立只读操作；没有新增配置项或修改波特率。

## 验证状态

开发机 Debug 构建及 45/45 项 CTest 通过；另用开发机本地 Broker 验证 QoS 2 完成回调（5 项测试、299 条断言通过）。伪终端和构造 MAVLink 帧仅验证本端逻辑。实验箱未通电，ARM64 构建、现场 B0、接线、F407 实烧协议、真实完整帧、MQTT 路由/入库与 Web 显示均未核验。代码未推送、未部署。详情和合成 ACK 见[离线实现与待验收](../阶段一H1真实回显树莓派端离线实现与待验收.md)。

## 停止门

三端共同冻结字节契约、核实 Server 来源与 Session 门禁并取得用户部署授权前，不在实体 Pi 上启用回显动作。`HELLO CNS`、示例速率和构造帧不能作为实机证据。
