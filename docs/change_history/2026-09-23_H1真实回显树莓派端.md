# 阶段一 H1 真实回显树莓派端

日期：2026-09-23

## 变更摘要

按候选跨端契约在原 MQTT/串口主进程增加受限学生文本 `uart_echo`：严格解析请求、复用唯一 MAVLink 串口读写者、保存完整帧和已应用速率、匹配 F407 原样回显及本动作后新业务帧、发布 QoS 2 终态 ACK。新增发帧前持久化去重记录，防止进程崩溃后同一动作盲目再次发送；ACK 只有获得 MQTT 完成回调才移出待发队列。旧 `inspect_pi_link` 仍为独立只读操作；没有新增配置项或修改波特率。

## 验证状态（隔离阶段）

开发机 Debug 构建及 45/45 项 CTest 通过；另用开发机本地 Broker 验证 QoS 2 完成回调（5 项测试、299 条断言通过）。2026-09-23 在树莓派临时目录以 ARM64 原生构建提交 `f0eefb2`，45/45 项 CTest 通过；随后使用仅监听本机环回的临时 Broker，让 H1 进程独占 `/dev/ttyUSB0`，取得当前 F407 对 `H1 LIVE 01` 和 `你好 CNS` 的真实原样回显与完整 TX/RX 帧，双方报告速率均为 115200，新业务帧为真。过期拒绝与重复动作不重复发帧也已实测。生产 Pi 已恢复原提交 `a618548`，代码未推送、未接入现网。F407 实烧版本、逐线接线、MQTT 路由/入库与 Web 显示均未核验。云端 Broker 当前允许匿名连接且无 Topic ACL，生产路由/后端尚未检出 H1 实现，直接上线存在来源绕过风险。详情和原始 ACK 见[本端验证与待验收](../阶段一H1真实回显树莓派端离线实现与待验收.md)。
