## 本次行为

- `OPEN_DRONE_ID_BASIC_ID.uas_id` 是持久化绑定与 MQTT Topic 使用的稳定 `device_id`；可修改的 `DCDW-XXX`、LoRa 节点编号及 MAVLink `system_id` 均不能作为唯一身份。
- 已绑定 F407 在同一串口发出同组件的新 `system_id` 心跳时，Pi 保持串口、MQTT 控制入口与实验会话，撤销当前身份核验，暂停新的 F407 串口下行。候选 Basic ID 与绑定 `device_id` 一致后才切换端点，并更新可读标签及串口拓扑记录；候选身份冲突不自动改绑。
- 换号前已发出的 H1/M1 动作不因身份暂失主动中断，仍按原响应等待、有效期和不确定结果规则结束。待复核期间新到达的 H1/M1 串口动作最多暂存一项；有效且串口空闲时才移交原事务，过期按原事务生成终态。普通 `control/set` 仍由原身份门禁拒绝，不进入待发槽。
- 待发动作即使在身份复核完成后仍占槽，也继续拦截同动作重投。槽满、身份冲突或真实串口断开形成的拒绝终态先进入 H1/M1 原有持久化去重记录，避免同一动作后来重试时被物理执行；同 ID 不同内容的冲突消息仍按原事务的“冲突重投”语义单独拒绝，不覆盖槽内原动作。
- Pi 本地 `set_pi_baud` 在待发槽为空时仍按原门禁处理；槽被占用时必须先比较动作 ID，不能抢占槽内 H1/M1 动作或改写其去重结果。
- 3 秒是未取得候选 Basic ID 的一次性告警门槛，不是自动切换或结束实验的条件。真正串口断开仍按原物理故障路径处理。
