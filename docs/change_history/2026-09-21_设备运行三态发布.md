# 设备运行三态发布

## 变更摘要

树莓派端补齐主控箱运行三态发布，在 `{namespace}/{device_id}/runtime/status/v1` 以 QoS 1、retained 上报 Pi 控制链、F407 业务链和身份核验状态。状态变化时立即发布，MQTT 首次连接和每次重连后强制重发，不增加周期心跳。主控箱异常断线的 MQTT Last Will 改为合法的 `offline|unknown|cached/unbound` 组合。

增加最小持久化身份绑定。首次真实 F407 Basic ID 原子建绑，重启或串口暂时失联时使用缓存恢复 MQTT 控制入口；身份一致后转为已核验，冲突时保持原 Topic 和绑定并阻断冲突设备的遥测与控制。串口释放与 MQTT 生命周期解耦，F407 静默满 10 秒只改变业务状态。

代码评审后补齐身份会话边界：新串口链路不能继承旧链路的核验资格，未绑定候选变化不会造成内存与磁盘身份错配，身份未核验或冲突期间的普通帧不进入共享遥测缓存。连接成功回调使用递增代次通知主循环，避免快速断线重连被布尔轮询漏采；绑定从 unbound 转为持久化后重建 MQTT 客户端并更新 Last Will。

## 影响范围

- 增加运行三态协议模型、事件发布判定和 F407 会话状态；
- 增加 `/var/lib/cns-rpi/device_binding.json` 身份缓存及配置项；
- 示例配置增加固定 runtime Topic；
- 主程序切换主控箱 Last Will，正常退出仍主动发布 runtime 与 registration 离线状态；
- 更新 README、V1 设计、验收和回滚说明。

## 本地验证

新增覆盖 Topic/QoS/retain、在线载荷、两种 Last Will、非法离线组合、10 秒静默与恢复、四种身份状态、不重复周期发布、重连强制发布、绑定文件和串口/MQTT 生命周期解耦的自动化测试。Debug 构建及 41 项 CTest 全部通过；QGC UDP 测试在允许本地 UDP 套接字的环境通过。
