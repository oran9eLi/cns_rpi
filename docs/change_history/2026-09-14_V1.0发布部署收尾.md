# V1.0 发布部署收尾

## 变更摘要

发布基线保留主控箱/PX4 统一身份、现有 MAVLink 解析和高低频遥测。移除主服务配置卷依赖，安装入口不再安装配置挂载服务；旧只读根或配置卷设备须先备份迁移。

部署在临时副本完成遥测配置迁移及 C++/Python 双重校验后才写入现场配置、安装并启动两个服务。补齐 Mosquitto 构建库及网络工具依赖、两个服务的串口权限。CMake 版本为 1.0.0，提供版本查询和无硬件配置预检。现场参数继续保留在 `/var/lib/cns-rpi/config.json`。

## 影响范围

部署脚本、两个 systemd 单元、主程序 CLI、版本信息和 V1/M7/部署文档。协议及现有 PX4 解析范围不变。Release 构建中发现的旧测试短字符串越界读取与日志警告同时修正。

## 验证结果

开发机 Release 构建成功，38 项 CTest 全部通过（包含版本/配置检查及临时目录部署模拟），Shell 语法及 Git 差异检查通过。QGC UDP 用例在沙箱外验证通过，原沙箱内失败属于环境限制。代码复查发现的 5G 参数预检遗漏已修正。

## 未完成项

ARM64 与新树莓派安装、重复部署、重启自启动、5G/串口恢复和 PX4 实机验收尚待执行。千设备高频容量指标未验证。当前是发布候选准备，尚未创建正式标签或 GitHub Release。
