# 主控箱六动作 V0.1 接口变更

日期：2026-11-16。依据为用户确认的两份 V0.1 软件部/F407 端接口稿，当前内部约定见 [主控箱控制接口](../下行飞行控制协议.md)。

## 变更范围

- 新增 `arm=31093`、`disarm=31094`；保留起飞、降落、急停命令号。
- 调速改为 `set_motor_pwm=31014`，请求使用 `motor_id=1..4` 与单个 `pwm_us=1000..2000`。旧 31013 四路 PWM 数组不再接受。
- `parameters` 为必需字段，无参数命令传 `{}`。`accepted` 改为 F407 已受理，不表示动作完成；2 秒受理超时表示执行状态未知，不自动重发，不等待旧进度或完成 ACK。
- F407 拒绝原因由 `COMMAND_ACK.result_param2` 映射为设备未解锁、忙、参数非法、状态不允许及起飞检查失败等错误码；未细分拒绝使用 `mcu_rejected`，不支持命令使用 `unsupported_command`。
- 等待普通受理时，允许不同命令号的上锁、急停优先下发并独立匹配乱序 ACK；同号在途及超时后 10 秒迟到隔离统一返回 `command_busy`。
- 六类业务控制只在 F407 明确拒绝后追加 `TUNNEL/0x8040` 的 `01 00` 失败声光。接受、本地拒绝、链路失败、受理超时均不追加控制提示；配置和实验终态提示规则保留，上锁/急停打断串口实验时抑制中止提示，避免覆盖停车声光。
- F407 负责电机、声光、锁状态和动作门禁；Pi 透传 `HEARTBEAT.base_mode` 的掩码 128，不实现固件动作或替代性锁状态。
- 本地 CLI、测试夹具和内部说明同步新接口。旧历史设计、计划和实机记录保留当时语义；如有冲突，以当前接口为准。
