# Web 发起远程更新与 CI：Pi 侧候选实现

日期：2026-11-03。候选版本：1.0.6，尚未发布标签或部署生产设备。

## 产品行为

Web 选择设备、版本后点击更新，后端经 MQTT 发消息，服务器订阅并创建持久化任务。Pi 主动领取、从服务器下载 CI 预编译 ARM64 包、按组件安装并回报。Web 显示实际终态。树莓派不需要公网入站地址或现场编译工具。

## 本仓库变更

- 独立 bootstrap 脚本、包内安装器、systemd 维护 timer；app/cellular 分别切换与回退。
- 保留现场配置/身份/实验状态，业务更新不重启 5G；配置/helper 跟随业务版本。失败观察触发旧组件恢复，同版重装仍检查健康并保留有效回退目标。
- 任务结果落盘、重复任务回报、终态确认后才接下一任务；断网保留结果，中断任务报需处理。
- 固定文件清单打包、ARM64 ELF 校验、版本/提交/摘要清单；普通用户 trixie ARM64 CI，真实 Mosquitto 收发/受控重连，runtime-only 容器检查，标签版本匹配才发布。
- 新增服务器 MQTT/HTTPS 接口契约，单独管理 Pi node_id 与业务 device_id。服务器现有普通命令在线/会话门禁和短超时不能直接用于更新任务。

## 已验证与证据

WSL Ubuntu-24.04 完成本分支 CMake 构建；完整 59 项 CTest 和额外 16 项独立拨号测试通过。真实 Broker 测试启用两个环境变量并观察到停止/重启标记，不是条件跳过。新增测试执行真实安装目录/配置切换与本地 HTTP 客户端联合流程，平台执行和 systemd 使用边界替身。

审阅修复了限制 umask 导致目录不可遍历、服务停止错误阻断恢复、同版重装覆盖回退记录及跳过健康检查的问题。CI 修复为普通用户运行测试。构建/测试日志位于本工作树忽略的 `.superpowers/sdd/2026-11-03-rpi-web-update/`，最终记录见后续补充。

## 未验证与跨仓库工作

本地为 x86_64 WSL，没有 Docker/ARM64 执行环境；GitHub ARM64 作业、真实版本包 runtime-only 运行和 Release 发布须以现网 CI 结果为准。实体 Pi 首装、systemd/watchdog/权限、纯 5G 更新和失败回退需现场验证，不能以服务替身代替。

服务器仓库本次只读，尚需实现更新消息订阅、版本托管、节点映射与认证、持久任务 API；Web 后端和更新按钮也需按契约接入并联调。目前不能称最终 Web→Pi→Web 产品效果已完成。远程 MAVLink 和旧实验/硬件验收没有实施。
