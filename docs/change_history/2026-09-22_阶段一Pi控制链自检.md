# 阶段一 Pi 控制链自检

日期：2026-09-22

## 变更摘要

主控箱已持久化绑定时，在现有 MQTT 会话增加只读 `inspect_pi_link` 订阅与终态 ACK；从现有状态机和串口持有者读取四项事实，加入过期校验、有界去重及失败后原 ACK 重发。未改变串口收发、波特率、F407 固件或 Server/Web。

## 影响范围

对应[冻结契约](../2026-09-22-阶段一Pi控制链自检跨端契约.md)第 2 至 5 节。新增实验消息只走主控箱固定 Topic；既有配置、飞控、注册和遥测消息处理分支保持原有语义。

## 验证结果

本地 CMake Debug 构建通过，未出现编译警告；`ctest --test-dir /tmp/cns-rpi-pi-inspect-build --output-on-failure` 为 42/42 通过，包含现有配置、飞控、注册及遥测回归。独立 Mosquitto 重启检查为 1/1 用例、11/11 断言通过：首次 QoS 2 收发成功，断线后客户端检测离线，Broker 在原端口重启后订阅自动恢复并再次收发。实体树莓派 ARM64 原生构建和 42/42 测试通过，直达 MQTT 自检收到真实 `completed` 和过期 `rejected` ACK；精确部署记录见[实现与验证](../阶段一Pi控制链自检实现与验证.md)。

## 遗留事项

Pi 进程重启后不保证恢复先前只读动作的进程内终态缓存。还需验证身份 `cached`、F407 业务离线的现场组合，以及 Server/Web 端真实 ACK 接收、落库和展示；F407 `HELLO CNS` 真回显及参数实验不在本次范围。
