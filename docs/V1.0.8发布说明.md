# V1.0.8 发布说明

本版在 V1.0.7 与最新 RTK 基站、移动站实验的基础上，更新主控箱常规状态上报。

- 沿用 `runtime/status/v1`，改为十字段设备资料及状态帧，QoS 1、retained，每 10 秒及连接、内容变化时发布。字段定义见[常规设备状态上报](常规设备状态上报.md)。
- `model_version` 上报树莓派应用版本 `1.0.8`；删除 `version`、`provisioned_at`。学校使用现场 `identity.school_name`，名称默认 `CNS 一代实训平台`。
- 各 F407 模块只累计设备运行中的离线、故障时间，任一模块连续累计 12 小时报损坏；重启续计，关机不计。未知、启动暂停计时，在线、降级、主动关闭结束连续故障。
- 维修标记保持至明确解除；本版仅提供内部接口，Web 修改握手与云端资料下发尚未接入。设备 ID、应用版本、在线声明只读。
- 保留 RTK 三串口隔离、缓存箱子身份下的 RTK 观测与移动站实验，以及 G2 视频功能。

## 安装与验证

发布工作流生成 Debian trixie ARM64 安装包、清单与 SHA256。升级保留现场业务配置；业务组件升级只重启 `cns-rpi.service`。

旧源码部署须先备份并建立与实际程序一致的安装基线，再使用维护客户端；首次部署说明见[远程更新部署手册](远程更新部署手册.md)。常规状态主题的消费者须按十字段新契约读取。

CI 覆盖完整回归、原生 ARM64 构建与纯运行时安装检查。实机、任务 API 与正式 Web/5G 闭环的结果应分别记录，不以构建通过代替现场验收。
