# BMI088 上行接口设计记录

日期：2026-11-12。用户已将 Pi→服务器接口的选择交由本端确定，并要求严格按该文档实现。

完整合同与 JSON 样例见 [IMU 原始与解析数据接口](../../IMU原始与解析数据接口.md)。

采用解析值复用既有快照／实时遥测、完整 RAW＋PARSED 采样对使用 `imu/sample/v1` 的接法。相比把原文塞入周期遥测，采样对按源节奏发布且便于去重；相比 GNSS 式控制和归档流程，本版直接提供持续观测所需的数据，不增加独立采集状态机。

实现使用现有 C++ 单串口读取器。参考 Python 解码器与机器字段表不作为依赖。保留 F407 单位、采样 key、原始 64B 字节、200ms 有效性和来源生命周期，服务器负责显示与可选归档；其他状态、控制和更新接口沿用现有合同。

Pi 侧实现和本地软件验证见 [实施记录](../../validation/2026-11-12-bmi088-uplink.md)。ARM64 构建、实机和跨端验收须单独验证。
