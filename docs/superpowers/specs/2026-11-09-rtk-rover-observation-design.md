# RTK 移动站实验与真实数据观察

用户已选择不依赖 QGC，通过网页观察收敛，并授权完善树莓派。本次只修改 Pi 仓库。

## 范围

沿用一个 cns_rpi 服务、F407 箱子绑定身份、experiment/set 和 experiment/ack。合法缓存身份仍可操作，PX4 只作为下挂观测源。增加本地 RTCM→GPS_RTCM_DATA 转发、暂停/恢复，以及有界的真实协议样本；不修改服务器、F407 或网页，不控制飞行，不设置 PX4 参数。

## 数据路径

BaseStation 在现有 CRC24Q 校验后交付完整 RTCM 帧，最多保留 32 帧，溢出计数；坏帧不能进入转发。ExperimentService 独占 3DR 的现有读写者，先处理遥测和心跳，再顺序发送改正分片。停止、暂停、链路失效期间收到的帧只观察，不留待恢复重放。

转发仅在用户显式开始/恢复、基站 freshly verified 且 survey_in.completed、PX4 当前身份在线、当前帧年龄不超过 1 秒时进行。无可转发数据时报告等待原因，不把开始动作完成写成 Fixed。进程重启后默认停止；短时 MQTT 失联不切断已经启动的本地改正链路。

GPS_RTCM_DATA 使用官方生成头，180 字节分片，5 位 sequence。整倍数且不足 720 字节的组追加空尾片；超过一组的完整 RTCM 帧按顺序分组交付接收机字节流，不截断。每次 Tick 发送有界帧数；不在教学遥测中复制全量流。

## 教学观察

- 基站：真实 NAV-SVIN 帧与字段、RTCM 消息号/用途/长度/CRC/完整十六进制样本。
- 传输：同一 RTCM frame sequence 关联实际写入成功的 MAVLink 原帧、消息号233、flags/fragment/sequence/len、有效载荷；不伪造接收端 ACK。
- 移动站：GPS_RAW_INT 的独立样本序号、接收/源时间年龄、fix_type/卫星数/位置/估计精度、真实原帧；同一 source time 重复帧不能刷新测量年龄。
- 有界近况：最多 16 个定位状态变化，记录本次实验时间；不保证出现 Float，不把未知或过期 Fixed 当当前固定解，不把估计 h_acc 称为实测绝对误差。

完整协议样本只进入低频快照、动作回执和本机状态文件；高频实时遥测只含计数、状态与年龄。窗口固定容量、有 sequence 与淘汰计数，明确不是完整抓包。原始字节来自现有串口读取/成功写入，不另开串口。

## 操作

新增 rtk_rover_start / rtk_rover_pause / rtk_rover_resume / rtk_rover_stop / rtk_rover_status。与原状态操作使用相同的九字段信封，不接收任意 MAVLink/串口字节，复用现有目标、过期、租约、动作去重和 ACK 队列。基站操作不变；测量期间暂停转发，不能把旧基站改正继续发出。

## 验证边界

用真实 C++ 实现、PTY、独立 Mosquitto 和完整进程验证原字节、分片、暂停/恢复、坏CRC、GPS冻结与身份边界。室内实体只验证实际可取得的基站/PX4/云端链路；真实卫星收敛、Fixed、断改正退化与恢复必须室外验收。
