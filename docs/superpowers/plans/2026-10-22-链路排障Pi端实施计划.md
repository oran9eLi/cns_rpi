# 链路排障实验 Pi 端实施计划

状态：跨端设计与实施计划已确认；本文仅拆分 Pi 端工作。Server 和 Web 任务不在本仓库实施。

## 目标与边界

沿用已持久化主控箱身份对应的 `experiment/set` 与 `experiment/ack`，实现四类 `link_lab_*` 命令。实验覆盖仅在当前进程内生效：改变发送给 F407 的 `RPICELL` 在线位、暂停或恢复该报文、在线改变唯一业务串口的波特率。真实 5G、MQTT、遥测快照和持久配置均不变；进程重启回到持久配置。F407 固件不修改。

## 实施步骤

1. 先补请求解析、到期/租约/重复动作和 ACK 字段测试，再实现严格解析、会话隔离及有界终态缓存。拒绝 ACK 不带 `fact`。
2. 先补 `RPICELL` 覆盖、暂停、首次断开必须真实写帧及恢复的失败测试，再实现独立状态机；发送事实只表示 Pi 完整写入 UART，不表示 F407 屏幕已更新。
3. 先补临时换速、失配后固定目标速率探测、重启清除及恢复测试，再接入主循环的唯一串口所有者。不得开第二个读者，也不得把实验速率写入 `config.json`。
4. 复用现有实验 ACK 待发队列，回归配置、注册、遥测、飞控及既有实验。同步协议说明和示例；构建、全量测试后提交。部署前核对 Server 路由版本、设备版本、串口拓扑和回退路径，再按已授权的现场范围测试。

## 现场验收边界

Pi 的 ACK 及串口写入能证明 Pi 侧动作；F407 灯色、实际业务帧恢复和 Server 实验视图仍须分别记录真实观测。任何失败均保留原状和证据，不用模拟结果替代真机结论。
