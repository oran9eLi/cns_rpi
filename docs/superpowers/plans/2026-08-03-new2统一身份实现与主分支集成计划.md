# new2 统一身份实现与主分支集成实施计划

> **供智能体执行：** 必须使用 `superpowers:executing-plans`，按任务逐项执行并在提交、合并和推送前使用 `superpowers:verification-before-completion` 验证。

**目标：** 将 `8cc39a6` 中主控箱/PX4 统一身份实现移植到 `new2`，排除 `new3` 的 QGC 双入口改动，验证后合并并推送 `main`。

**架构：** 以 `new2` 为目标基线，只应用 `8cc39a6` 相对其父提交的身份补丁。身份仍由 `OPEN_DRONE_ID_BASIC_ID.uas_id` 唯一确定，PX4 产品版本仅作为注册元数据；树莓派不持有业务身份。冲突文件以 `new2` 现有功能为底稿，手工加入身份逻辑，不引入 `new3` 的 QGC 配置、桥接策略或测试。

**技术栈：** C++23、MAVLink C library v2、nlohmann/json、Mosquitto、CMake、doctest、Git。

## 全局约束

- 文档、注释和用户沟通使用中文；Git 提交前缀使用英文。
- 新确认的身份协议、字段或运行行为必须同步设计文档和变更记录。
- 不引入 `new3` 的 QGC 双入口相关代码、配置、文档和测试。
- 不恢复 `vendor_id`、`remote_id`、PX4 `uid/uid2`、`gateway_id` 或 `rpi_serial` 作为业务身份。
- 注册和常规遥测使用 schema v3；服务器端已完成兼容更新并通过测试。
- 用户已确认将完成后的 `new2` 合并到 `main`。
