# F407 初版控制接口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 树莓派按已确认的两份 V0.1 接口文档实现六动作、受理回执和拒绝声光。

**Architecture:** 复用现有 MQTT、MAVLink 串口和端点核验。解析器负责请求入口和编码；事务层允许不同命令号的上锁、急停优先受理；主循环转发真实受理结果，声光模块仅在 F407 明确拒绝控制命令时发送失败提示。

**Tech Stack:** C++23、nlohmann/json、MAVLink 2、Mosquitto、doctest、Python、WSL Ubuntu 24.04 GCC15。

**Spec:** 桌面 `CNS控制接口_初版评审/CNS控制接口_软件部_V0.1.md` 与 `CNS控制接口_F407端_V0.1.md`，2026-11-16 用户批准实现；内部稳定说明更新至 `docs/下行飞行控制协议.md`。

## Global Constraints

- arm=31093、disarm=31094、set_motor_pwm=31014（param1电机1..4，param2脉宽1000..2000μs）；其余现有三动作号保留。
- accepted只表示受理，不表示完成；2秒超时是执行状态未知，不自动重发，不追加控制声光。
- 仅F407明确拒绝控制时发送 TUNNEL/0x8040 数据01 00；配置与实验提示保持原规则。
- 锁门禁和电机声光时序由F407执行；Pi透传HEARTBEAT.base_mode掩码128，不另猜锁状态。
- 不修改STM32固件，不连接执行机构，不部署、推送或发版。
- 保持入口校验一次；不增加协议令牌或维护状态机。

## Review Focus

- 等待普通受理时上锁/急停能立即下发，乱序ACK各自匹配。
- 相同command_id重放不重复执行或提示，同号不同请求不能误配ACK。
- 成功、超时、本地校验拒绝都不得产生控制声光；明确F407拒绝只提示一次。
- 非本机端点、身份冲突、实验串口占用/恢复不得把控制发错设备。
- 旧四路PWM样例、CLI测试、网关夹具和内部说明全部更新。

## Decisions

- COMMAND_ACK只有命令号：不引入额外请求ID，同号并发返回command_busy，超时后沿用现有10秒同号隔离；该限制补入软件接口文档。
- 两份桌面MD是用户指定交付物，继续原位维护；内部文档记录完整实现约定，不把本地验证结果写入对外文档。
