# BMI088 Uplink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 按已定义合同接收 BMI088 三种帧，并在真实 Pi 主进程发布三类 MQTT 数据。

**Architecture:** 一个入口解码三种 64B 小端 payload，交给独立 IMU 流对象完成配对、来源生命周期和时效计算。主程序复用唯一 UART 接收器，将快照／实时 JSON 增量及新样本发布接入现有 MQTT。

**Tech Stack:** C++23、现有 MAVLink C 库、nlohmann/json、doctest、Python PTY、Mosquitto、WSL Ubuntu 24.04。

**Spec:** `docs/IMU原始与解析数据接口.md`；线协议 `docs/protocols/BMI088原始与解析数据_树莓派MAVLink接口.md`。

## Global Constraints

- 不改 Topic、字段、单位和 schema；snapshot=3/realtime=1/sample=1，QoS 0、retain=false。
- 新源最多 5Hz；普通实时默认 10Hz 只重复当前样本，过期不能续期。
- 200ms 当前值有效期；1 秒未齐组清理；STATUS 超过 3000ms 标记过期。
- 只在边界校验；不改自动生成 MAVLink、F407、Server 或设备配置。
- 本轮本地实现与软件验证，不推送、发布或部署。

## Review Focus

- 同一样本两包交错、重试编码时刻变化，仍能配对且只发布一次。
- 队列等待超过 200ms、断流或源撤销后，不以重复帧重新授权业务值。
- STATUS 当前初始化次数与最近测量不同，不参与 RAW/PARSED 配对。
- MCU 时钟／采样序号回退、串口重连、身份冲突不会拼接前一来源的半包。
- SPI 地址、无诊断、未知年龄、有效零值和非零温度低保留位按文档处理。
