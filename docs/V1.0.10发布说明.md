# V1.0.10 发布说明

## 主要变化

- 通过现有 MQTT `control/set` 接口启停 GNSS、IMU、气压计、LoRa 和 Remote ID。F407 开启模块时请求切到对应页面，关闭时留在当前页。需搭配支持 MAVLink `31015` 的 F407 固件。控制回执表示 F407 已受理，页面绘制和新数据采集由固件后续处理。见 [主控箱控制接口](下行飞行控制协议.md)。
- 树莓派忽略 broker 重发的保留控制消息。同一设备重建 MQTT 会话时，保留进程内的命令去重结果和迟到回执隔离。
- 树莓派收到气压计停用状态后，快照和实时遥测省略 `telemetry.pressure`。重新开启后，收到新采样才恢复上报。

## 安装与升级

发布包 `cns-rpi-1.0.10-trixie-arm64.tar.gz` 适用于 Debian trixie ARM64。安装前核对 `manifest.json` 和 SHA-256 文件。已有维护安装器的设备可更新 `app` 组件，沿用现场配置、设备绑定和故障累计。见 [远程更新部署手册](远程更新部署手册.md)。
