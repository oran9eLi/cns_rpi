# V1.0.9 发布说明

日期：2026-11-17。

本版在 V1.0.8 基础上新增 F407 主控箱六动作控制，并整合状态、IMU、GNSS 与数据上报周期接口。

## 主要变化

- 支持 `arm`、`disarm`、`takeoff`、`land`、`emergency_stop`、`set_motor_pwm`。控制回执区分已下发、F407 接受／拒绝及超时；`accepted` 仅表示已受理，超时表示执行状态未知，不自动重发。F407 明确拒绝时，Pi 追加失败声光通知；接受后的动作与声光由 F407 执行。
- 调速改为单电机 `motor_id=1..4`、`pwm_us=1000..2000`；旧四路 PWM 数组不再接受。所有请求须提供 `parameters`，无参数动作传 `{}`。上锁和急停可优先下发，具体请求与回执见 [主控箱控制接口](下行飞行控制协议.md)。
- 常规状态新增只读 `fault_modules`，形成十一字段；旧版 V1.0.8 为十字段。异常模块立即列出，既有 12 小时运行故障累计与重启续计规则保留。实体主控箱类型统一为 `cns_box`，`model_version` 为 `1.0.9`。详见 [常规设备状态上报](常规设备状态上报.md)。
- 接入 BMI088 原始＋解析采样对，经 `imu/sample/v1` 上报；解析结果同时进入既有遥测。格式与来源有效期见 [IMU 原始与解析数据接口](IMU原始与解析数据接口.md)。
- 增加 GNSS 原帧观察实验，经 `gnss/raw/v1` 上传原始报文批次；普通定位继续沿用原有遥测。配置与采集边界见 [GNSS 实验接口](GNSS实验接口与服务器对接.md)。
- 支持五类数据 Topic 周期远程修改、持久保存及运行中生效；GNSS 调整组批周期并保留全部原帧，注册和 ACK 仍立即发送。取值范围及语义见 [Topic 上报周期控制接口](Topic上报周期控制接口.md)。
- 保留 RTK 基站／移动站及视频实验功能，以及配置、实验命令的终态声光提示接口。

## 安装包与升级

发布工作流生成 Debian trixie ARM64 安装包 `cns-rpi-1.0.9-trixie-arm64.tar.gz`、`manifest.json` 与 SHA-256 校验文件。安装前核对版本、源码提交、目标平台和校验值，实际源码提交以清单为准。

已有维护安装器的设备使用 `app` 组件更新，保留现场配置、设备身份绑定、健康累计与回退版本；业务更新只重启 `cns-rpi.service`，不重启整机或 5G 拨号服务。旧源码部署和首次安装按 [远程更新部署手册](远程更新部署手册.md) 建立安装基线，不用样例配置覆盖现场配置。

## 对接边界

新增控制动作需要 F407 固件实现对应协议，树莓派受理回执不表示实际电机、蜂鸣器或灯光动作完成。服务端需按本版接口解析十一字段状态、新增数据 Topic 和控制回执；Web 修改设备资料的握手机制尚未接入。

CI、安装包核验和现场联调结果分别记录，发布说明不替代实际动作或跨端验收。
