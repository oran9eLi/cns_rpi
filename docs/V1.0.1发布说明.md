# V1.0.1 发布说明

版本：`v1.0.1`。发布日期：2026-09-21。

工程版本为 `1.0.1`。本版本在 V1.0.0 统一身份、遥测发布、命令转发、串口恢复和 5G 链路管理能力之上，补齐新版设备接入基线要求的主控箱运行三态。

## 主要变化

- 新增 `{namespace}/{device_id}/runtime/status/v1`，以 QoS 1、`retain=true` 发布 MQTT 控制链、F407 业务链和身份核验状态；状态变化时立即发布，MQTT 重连后强制重发。
- 新增合法的运行三态 Last Will。Pi 异常断线时由 Broker 保留 `offline | unknown | cached/unbound`，不将无法确认的 F407 实时状态误报为离线或已核验。
- 新增 F407 身份绑定缓存。首次合法身份原子写入，重启后可使用缓存恢复 MQTT 控制入口；身份冲突时保持原绑定，不自动改绑，不转发冲突设备遥测和控制命令。
- 串口与 MQTT 控制生命周期解耦。F407 业务静默满 10 秒只将业务状态改为离线，Pi 的 MQTT 控制入口保持运行。
- 补充运行三态配置示例、协议说明、维护边界、自动化测试和跨端验收步骤。

## 兼容性

- registration、完整快照、实时遥测、配置命令和主控箱控制命令的既有 Topic 与载荷保持不变。
- Server/Web 需支持新版设备接入基线中的运行三态 Topic；运行三态与 registration 在线状态相互独立。
- 旧现场配置缺少 `mqtt.topics.runtime_status` 或 `identity.binding_file` 时使用兼容默认值，建议在维护窗口同步示例配置，便于审计。
- PX4 不具备 F407 业务链和固定绑定语义，本版本不为 PX4 发布主控箱运行三态。
