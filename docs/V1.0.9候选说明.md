# V1.0.9 候选说明

日期：2026-11-11。

本候选包在已合并的 main 基线 `7432de6` 上增加异常模块明细，保留该基线的 GNSS 原始帧观察实验、RTK 基站／移动站实验及 G2 视频功能。候选软件版本为 `1.0.9`，实际源码提交以安装包 `manifest.json` 为准；本说明不代表已创建正式 GitHub Release，正式发布的 v1.0.8 包保持不变。

## 状态帧变化

- 沿用 `runtime/status/v1`、QoS 1、retained、10 秒周期及内容变化立即发布，状态帧从十字段增加为十一字段。
- 新增只读 `fault_modules`（`string[] / null`），说明已核验的 F407 离线／故障模块；未满 12 小时也立即列名。无已确认异常为 `[]`，不可核验且没有保留的致损模块为 `null`。
- 已累计满 12 小时的致损模块原因跨进程重启或 F407 断开保留，直到明确恢复在线、降级或主动关闭。既有运行故障累计、维修优先和健康文件格式不变。
- 实体主控箱的 `device_type` 默认值统一为 `cns_box`；`xn_box` 仅表示虚拟箱子。`model_version` 为 `1.0.9`。
- Broker 遗嘱中的异常列表仍为连接时快照，仅列表变化不额外重连。详细字段、模块名称与示例见[常规设备状态上报](常规设备状态上报.md)。

## 安装与验证边界

使用 CI 原生构建的 Debian trixie ARM64 候选包，以 `app` 组件安装到本次授权的 `.244`。保留现场 MQTT 地址、设备资料、串口、RTK、视频配置，以及身份绑定和健康进度；只重启 `cns-rpi.service`，不重启 5G 拨号服务。

候选包构建、完整回归和实际设备报文应分别验证并留存记录。本文件只说明候选范围与安装方式，不预先宣告 CI、部署、真实 F407 或 Server/Web 验收完成。
