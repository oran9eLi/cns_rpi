# BMI088 上行实现与软件验证

日期：2026-11-12。分支：`codex/bmi088-uplink`，起点 `c01a5ce`，本地开发。接口以 [IMU 原始与解析数据接口](../IMU原始与解析数据接口.md) 和随附 F407 UART6 v1 文档为准。

## 实现

- `src/imu/bmi088.*`：在已通过 CRC 的 TUNNEL 入口校验一次，解码 RAW64、PARSED64、STATUS64，保留全部内层原字节。
- `src/imu/stream.*`：同源采样 key 配对、重试去重、FIFO 最后一帧独立复算、轴映射、200ms 当前值有效期、1 秒未齐组清理和来源 UUID。
- `src/main.cpp`：沿用唯一 F407 串口读取器、身份核验及既有遥测开关；将 `telemetry.imu` 加入快照／实时，完整采样对以 QoS 0、retain=false 单独发布。MQTT 断连不缓存采样对，也不重置持续工作的串口来源会话。
- 参考 Python 解码器、机器字段表不是运行依赖；没有改变现有 ATTITUDE、十一字段设备状态、模块健康累计规则或控制接口。

## 可重复验证

在已安装仓库开发依赖的 Linux／WSL 环境执行：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure -R '^(bmi088_decoder|imu_stream|imu_gateway|imu_contract)$'
python3 scripts/ci/run_tests.py --build build --logs build/test-logs
```

| 测试 | 检查内容 |
|---|---|
| `bmi088_decoder` | 三种 wire 类型、MAVLink 裁尾恢复、有符号整数、SPI、温度低位、非法字段与右手轴映射；拒绝 present=true 且序号为 0，接受合法采样时刻 0。 |
| `imu_stream` | 三个文档样例逐字段一致；配对交错、重试、未齐组过期、数值复算容差、未知年龄、零时刻、STATUS null、来源切换及撤销；测量先到／STATUS 先到两种跨类型时钟回退均清除旧会话，正常的小幅编码交错保留会话。 |
| `imu_gateway` | 实际主程序经 PTY＋隔离 Mosquitto 发布三个 Topic；QoS／retain、原值、重复不重发、过期变 null、来源撤销、错误端点、缓存 SN 门禁、遥测关闭仍上传采样对；断线期间继续送完整采样对，重连后遥测能看到最新离线样本、原始 Topic 不补发历史、之后的新对仍可上传且 epoch 不变；ATTITUDE 和十一字段状态保留。 |
| `imu_contract` | Markdown 中前三个完整 JSON 示例与 C++ 测试使用的固定合同一致，防止接口文档和测试样例分离。 |

本次 Release 软件构建通过；新增代码编译未产生警告。四项针对性 CTest 通过，其中解码器为 85 项断言、流处理为 115 项断言，实际进程集成含三种场景。独立代码审查提出的保留序号、跨类型时钟回退和断线测试覆盖问题均已修正；提交前完整 `scripts/ci/run_tests.py` 返回 0：**80/80 CTest 通过**（115.53 秒），随后 **16/16 拨号测试通过**。

提交前复跑发现集成测试固定等待 1.1 秒收齐四组的假设不稳定，已改为在既有超时内等待实际收齐。对采样帧生成额外延迟 600ms 可稳定复现旧失败，修正后该场景通过；业务代码和发布节奏没有改变。

本地执行使用 WSL Ubuntu 24.04，构建目录 `/var/tmp/cns-rpi-status-20261109-build`。本轮原始 MQTT 软件观测记录保存在开发工作区的 `build/imu-implementation-20261112/mqtt-evidence.json`，提交前全量日志为 `build/imu-ci-20261112/prepush-tests-fixed.log`，构建日志为同目录 `prepush-build.log`；这些是忽略的本地证据，不是需分发的运行文件。

## 验证边界

输入为人工构造的 F407 数据，经过仓库现有 MAVLink pack／CRC 接收器，再交给实际业务实现。它验证本仓库的处理与 MQTT 交付，不代表实际 F407 编码器或 BMI088 硬件已经通过互操作验证。

本文记录本地实现阶段的验证，没有实体 Pi 测试，也没有修改服务器／F407。提交后的 ARM64 构建、运行时 smoke 和安装包产物以对应提交的 GitHub Actions CI 结果为准；推送分支不等于发布版本或部署设备。真实设备采样、真实编码器黄金帧及服务器/Web 联调仍待验证。
