## 延续已确认的发布目标

新树莓派一键完成依赖准备、构建、配置初始化、服务安装与自启动。保留主程序、5G 守护服务、配置原子写入 helper、日志限制与 watchdog；移除部署流程对 OverlayFS 和配置镜像卷的依赖。现场配置沿用已确认的 `/var/lib/cns-rpi/config.json`，更新仓库不得覆盖现场参数。MQTT TLS 本轮不新增。

2026-09-14 已确认：V1.0 一并发布当前已实现的 PX4 消息解析、统一身份和高低频遥测能力。通用遥测按 MAVLink 消息 ID 解析，共用状态存储和发布通道；身份请求、来源识别与命令适用范围仍存在设备类型判断。

当前通用解析覆盖 HEARTBEAT、AUTOPILOT_VERSION、GPS_RAW_INT、ATTITUDE、GLOBAL_POSITION_INT、SYS_STATUS、BATTERY_STATUS、SCALED_PRESSURE、SERVO_OUTPUT_RAW（前四路输出）。另有 OPEN_DRONE_ID_BASIC_ID、LOCATION、SYSTEM、OPERATOR_ID、SELF_ID 解析。身份继续使用 OPEN_DRONE_ID_BASIC_ID.uas_id，MQTT 仍需等待有效身份就绪。

发布现有解析能力不代表支持全部 PX4 消息、完整飞控控制功能或已通过全部 PX4 实机验收；主控箱私有控制命令仍禁止发送给 PX4。1000 台设备高频接入的容量指标尚不能作为发布承诺。
