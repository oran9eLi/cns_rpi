# V1.0 发布说明

版本：`v1.0.0`。发布日期：2026-09-14。

工程版本为 `1.0.0`，主程序支持 `--version` 查询版本，以及 `--check-config <绝对路径>` 离线配置校验；配置校验不打开串口或建立 MQTT 连接。

## 包含能力

- 单台树莓派接入一台 CNS 主控箱或 PX4，统一使用 `OPEN_DRONE_ID_BASIC_ID.uas_id` 作为设备身份；树莓派不提供独立业务身份。
- 保留已有 MAVLink 消息解析与状态汇聚，主控箱和 PX4 共用快照、实时遥测通道。快照默认 1 Hz，实时默认 10 Hz，详细字段以当前协议与解析实现为准。
- 保留主控箱现有命令转发、执行回执、运行时参数更新和自动重启机制；主控箱私有命令不适用于 PX4。
- 保留串口自动发现与断线恢复、RM500U 5G 常驻链路管理、质量上报和固件在线状态回传。
- 保留独立有界日志、journald 内存限额、主程序 watchdog，以及两个服务的开机自启动。

## 部署变化

使用普通可写根文件系统，现场配置位于 `/var/lib/cns-rpi/config.json`，不使用 OverlayFS 或独立配置卷。先准备仓库内 `config/config.json`，再执行 `scripts/install_deps.sh`，完成依赖安装、构建、配置初始化与服务安装启动。重复部署保留已有现场参数。

用户与仓库路径约定为 `dcdw`、`/home/dcdw/cns_rpi`。旧只读设备必须先备份并完成存储迁移，具体边界见 `docs/新设备部署手册.md`。

## 兼容性与范围

服务器需支持统一身份协议及 `telemetry/snapshot/v1`、`telemetry/realtime/v1`，再部署设备新版本。旧遥测 Topic 不双发，数据库消费快照、实时数据按需订阅。协议细节见 `docs/服务端对接-高低频遥测Topic迁移.md`。

PX4 支持范围为当前已实现的 MAVLink 消息解析、身份获取及遥测上报；下行主控箱私有协议不适用于 PX4。本版本使用 MQTT TCP 连接。

## 快速部署

目标系统：Raspberry Pi OS 64-bit（Debian 13 / trixie），以具备 sudo 权限的 `dcdw` 用户执行：

```bash
git clone --branch v1.0.0 https://github.com/oran9eLi/cns_rpi.git /home/dcdw/cns_rpi
cd /home/dcdw/cns_rpi
cp config/config.example.json config/config.json
nano config/config.json
./scripts/install_deps.sh
```

部署前填写 MQTT 地址、认证信息和物联卡 APN。串口与设备模式通常保持 `auto`。部署后可通过 `./build/cns_rpi --version` 查看程序版本。
